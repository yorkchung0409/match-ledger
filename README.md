# 赛场账本 · 比赛记录

手机端的比赛记账本：记下打了什么比赛、拿了第几名、花了多少、拿回多少。

**线上地址：<https://yorkchung0409.github.io/match-ledger/>**

整个应用就是根目录一个 `index.html`，零依赖、零构建，双击即可打开，也可以直接丢到任意静态托管。

## 记什么

- 比赛名可复用：先把常打的比赛录进「比赛管理」，记账时直接选
- 最终名次、收益、成本
- 时间用五列滚轮选择（年 / 月 / 日 / 时 / 分），日期自动联动
- 进圈档位：**圈外 / 进圈 / 进 FT**，记一笔时手动选，不按收益判断 —— 赏金赛圈外也能拿到淘汰奖励
- **币种**：每场单独选人民币或美元，两种桌子可以记在同一份账里
- **买入手数**：`×1` ~ `×5`，记这场一共买了几手（含 rebuy / add-on）

## 买入手数（rebuy）

扑克比赛常有 rebuy，账上它和成本是一回事，所以：

- **成本填总投入**：买了 3 手就是 500 × 3 = 1500，直接写 1500。手数不是算钱用的，它只是个标签
- 在「比赛管理」给某个比赛填**一手买入**（可选）之后，记一笔选中它会自动带出成本，点 `×2` 就按两手算 —— 之后还能手动改；换到没设价钱的比赛时，自动带出的成本会被清掉，避免张冠李戴
- 手数能看出两件比率算不出来的事：**场均几手**，以及 **1 手 vs 2 手以上 的进圈率差**。后者要注意自选择偏差 —— 买多手的场次往往本来就是被打崩、被迫续命的局，只能当参考
- 老记录没有手数字段，一律按 1 手处理，不需要迁移

## 币种与汇率

- 记录卡永远显示**当时的原币**（美元桌就显示 `$`），因为那是这一场的事实
- 所有汇总（首页大数字、走势、成绩结构、比赛管理）按同一份汇率折成你选的**统计币种**；记录页 hero 和数据页顶卡都有 `¥ 人民币 / $ 美元` 切换，两处是同一个开关
- 汇率每天自动取一次（`open.er-api.com`，失败退 `frankfurter` 欧洲央行数据），取不到就沿用上次的值，不阻塞任何操作
- 也可以手动填：数据页 → 数据管理 → **美元汇率**。填你实际换汇的价往往比中间价更贴近真实成本
- 汇率只影响折算，**不改任何一条记录的原始金额**；备份 JSON 和导出的 CSV 都保留原币

## 看什么

- **记录页**：累计净收益、场次、总投入、ROI、进圈率，按月分组；顶部可同时按比赛、盈亏（全部 / 盈利 / 亏损）、时间（年 / 月 / 日）筛选，三者叠加生效
- **数据页**：顶部「统计范围」按年 / 月 / 日圈定时间（和记录页的时间筛选共用同一个范围），走势、成绩结构、买入习惯、个人纪录全部跟着它走；下面依次是累计净收益走势曲线、成绩结构（圈外 / 进圈 / 进 FT 各自的场次占比与平均每场）、买入习惯（场均手数，1 手与 2 手以上分开算进圈率）、个人纪录（最大单场盈亏、最长连盈连亏）
- **比赛管理**：每个比赛的场次、进圈率、最好名次、成本与收益、场均净收益、场均手数

## 缺记录怎么算

记账之前的场次补不全，所以指标分两类口径：

- **比率类**（进圈率、ROI、场均、单场极值、连胜连亏）只看「已记录的场次」。没记住的场次不补、也不猜 —— 缺样本只会让结果有偏，不会把公式算错。
- **累计金额**（累计净收益、走势曲线）会被缺记录影响。在数据页 → 数据管理 → **期初结余** 填一个「记账之前已经累计」的总数：它加进首页的累计净收益（和场次、ROI 无关），走势曲线仍然只画记账以来，卡片底部会把「记账以来 / 期初 / 合计」三个数摆出来对账，避免一个大额期初把后半段曲线压成平线。

期初结余会一起写进 JSON 备份。

## 数据与备份

所有数据只存在本机浏览器的 localStorage（键 `matchledger.v1`），不上传任何服务器。
换设备请先用「备份数据」导出 JSON，再到新设备「恢复」。也可以导出 CSV 自己算。

读盘和恢复备份时都会先清洗一遍：不是对象的记录会被跳过并告知条数；时间不合法用创建时间补；成本/收益归一为非负数字；比赛名重复会重新分配 id。所以手改过的、被别的工具改坏的备份，多数能直接恢复进来，而不是让界面白屏。

真遇到界面画不出来，会弹一张兜底页，给三个出口：**导出原始数据**（未经整理的原文字节）、**尝试修复**（清洗后重载）、**清空重来**。整份 JSON 解析失败时，原文还会另存一份到 `matchledger.v1.broken`，不会被下次保存覆盖。

## 主题

右上角调色盘切换。六套主题各自是一套完整的视觉语言，不只是换色板 —— 圆角、描边粗细、阴影类型、字体、背景纹理会一起变，所以手感完全不同：

| 主题 | 配色 | 形态 | 细节 |
| --- | --- | --- | --- |
| 账本 | 墨绿 + 暖白 | 20px 圆角、细描边、克制投影 | 无纹理，最安静 |
| 甜心 | 樱花粉 + 奶粉底 | 26px 圆角、胶囊按钮、圆形徽章 | 奶油波点、粉雾柔光 |
| 数据 | 深蓝 + 冷白 | 小圆角、几乎无投影、靠细线分层 | 坐标网格、等宽数字 |
| 暖阳 | 暖橘 + 米黄 | 大圆角、暖色投影 | 纸纤维斜纹、宋体标题 |
| 梦境 | 紫 + 淡紫 | 30px 超大圆角、渐变卡面 | 双团紫粉柔光 |
| 极简 | 纯黑白 | 直角、2px 黑边、4px 实心投影 | 等宽数字，没有渐变 |

选择记在本地。
