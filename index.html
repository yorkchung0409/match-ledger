      口径与用法

      一句话：净收益 = 收益 − 成本；所有汇总按你选的统计币种折算；数据只存在这台手机上。

      一笔记录怎么填
      • 「成本」填这一场的总投入（含所有 rebuy / add-on），不是单次买入。
      • 「收益」填这一场拿到的钱，没进钱就填 0。
      • 「名次」会据此自动判档（进 FT / 进圈 / 圈外），也可以手动改。
      • 「比赛人数」填这一场的报名总人次（含重进 / rebuy）。同一比赛会自动带出上一次填的数，改一下就行。
      • 「手数」只是个标签，用来统计你平均买几手，不影响任何金额。
      • 同一场比赛可以反复选，比赛管理里就是按它横向对比的。
      这些数字怎么算
      • 净收益 = 收益 − 成本
      • ROI = 净收益 ÷ 总成本
      • 进圈率 = 进圈（含进 FT）场次 ÷ 常规赛场次
      • FT 率 = 进 FT 场次 ÷ 常规赛场次，和进圈率同一个分母。卫星赛没有奖金圈、也不设 FT，两个比率都不把它算进去；有卫星赛时首页小字会写明「比率按 N 场常规赛」
      • 场均净收益 = 净收益 ÷ 场次
      • 成绩结构按口径分两个 tab：常规赛看圈外 / 进圈 / 进 FT，卫星赛看赢到票 / 没赢到。每行右边是这一档的场均，不是这一档的总和 —— 6 场一共亏 $6.08，场均就是 −$1.01；想看总数就在记录页把这一档筛出来看顶部。
      • 成绩结构每行整行可点：点「进圈」就只看进圈场次，再点一次取消；卫星赛点「赢到门票」同理。
      • 比率只看已记录的场次。没记住的场次不补也不猜 —— 缺记录会让样本有偏，但不会把公式算错。
      比赛人数与进圈基线
      • 名次百分位 = 名次 ÷ 人数，记录卡上写成 32/420 · 前7.6%，意思是赢了 92.4% 的人。100 人场和 1000 人场可以直接横比，只看「第 32 名」比不了。
      • 「付费比例」在比赛管理里按赛事填一次（12 就是 12% 进钱圈），之后每场不用再填。它是赛事结构，改一次立刻作用于全部历史和未来，不需要逐条刷记录。
      • 首页进圈率下面那条基线就是它：基线 12% 表示同样打法随机打也有 12% 进圈。旁边标来源 ——赛事设定是准的，历史反推取你进圈记录里最差的一次名次百分位，一定偏低，样本不足 20 场不显示。
      • 人数填得够多之后，这条基线才说明问题：低于基线是生存能力不足，高出 5pt 以上通常意味着你拿决赛桌率换了进圈率。
      • 两者都只是分析维度，不进成本、收益、净收益、ROI；卫星赛没有奖金圈，一概不参与。删掉比赛名会连带丢掉它的付费比例，基线退回反推。
      • 人数和付费比例都齐了以后，如果名次排在钱圈之外却标了「进圈」，保存时会提醒一句，但不拦截 —— 档位还是你定。
      累计净收益与期初结余
      • 首页大数字是记账以来的累计。在「数据管理 · 期初结余」填一个记账之前已经累计的数，它会一起算进这个总账。
      • 期初不算场次、不进 ROI，也不影响进圈率、FT 率和连胜纪录。
      • 走势曲线仍然只画记账以来 —— 一个大额期初塞进曲线会把后半段压成平线，所以曲线底部用「记账以来 / 期初 / 合计」三个数对账。
      美元与统计币种
      • 每场可以单独记人民币或美元，账本里两种混着记也没问题。记录卡永远显示当时的原币，因为那是这一场的事实。
      • 汇总必须有一个统一口径：先按「数据管理 · 美元汇率」把不同币种折成你选的统计币种，再加总；改汇率不会改动任何一条原始记录。
      • 统计币种选过一次就记住，下次打开还是它。没选过时按人民币起手，折算过的数字下面会写明用的汇率。
      走势图三种切法
      • 场次：累计曲线，每个点按名次档着色（金＝进 FT、品牌色＝进圈、灰＝圈外）；超过 60 场只标 FT 的点。
      • 月度：每月一根柱，赚红亏绿，没打的月份是浅色短横线；「最差」「月均」只按有记录的月份算。
      • 比赛：按净收益排序的横条，中线是 0，往右赚往左亏；点一行跳到记录页，只看这个比赛。
      卫星赛与门票
      • 卫星赛赢的是更大比赛的门票，不是现金。票绑定本人、不能变现，所以不进净收益、不进 ROI，只记在数据页「成绩结构 → 卫星赛」的门票台账里。
      • 票不是一场比赛：不产生场次，不进进圈率、FT 率、成绩结构、买入习惯、个人纪录。台账里一张票一条，分「卫星赛赢到」和「获赠」两种来源。
      • 记一笔把「收益类型」选成「赢门票」，可以填每张票面值和张数；面值留空也能入账，现金收益自动算 0。
      • 用票打主赛时「成本来源」选「门票」或「票 + 现金」，并从列表里选中具体哪一张票 —— 赠票也能选，台账就能追到它是哪一场用掉的。现金成本只填自己掏的钱（rebuy / add-on），票面从台账带出、不算现金成本。
      • 免费获赠的票（没打过卫星赛）点「+ 登记赠票」：可一次登记多张，每张面值可留空，不产生场次、不进任何统计；只有票、没有卫星赛也能打开这个 tab。
      • 数据页「成绩结构」右上角切常规赛 / 卫星赛：卫星赛那边看命中率、赢到票 / 没赢到各多少场、每场平均花多少现金；下面是全库门票流水，未用 / 已用都能点开，可删、可跳到用掉它的那场。
      • 门票台账按全部记录算，不受时间范围影响 —— 查「还有几张票没打」要准。平均每张票花 ＝ 卫星赛现金成本 ÷ 赢到的票张数，获赠的票不进分母；未用票数按流水张数算，不再拿记录条数相减。
      • 在「比赛管理」里把这类比赛标成卫星赛：单独归类，不混进常规赛的进圈率、FT 率、成绩结构、买入习惯和个人纪录；但卫星赛买入是真花钱，仍照记进净收益和走势。
      • 老账本打开时会自动补出票流水：赢票面值变卫星赛票，用票却找不到更早的票就标成「获赠 · 来源未记」。现金数字一个都不动，配对不准可以在台账里删掉再登记。
      • 删记录时，由这场赢到的票一并移除，这场用掉的票退回「未用」；删票不影响任何现金金额。
      档位与比赛管理
      • 档位按记录时选的来，与收益多少无关 —— 赏金赛圈外也可能拿到淘汰奖励。
      • 比赛卡上的数字覆盖这个比赛的全部记录，不受页面顶部的筛选影响。
      • 比赛名可以反复使用；改名会同步到引用它的记录，删除比赛名不会删掉记录，历史记录保留当时的名称。
      筛选与时间范围
      • 两页各有一份时间范围：记录页顶部那个时间按钮只管列表，数据页顶部的「统计范围」只管统计。各存各的，在一页改了不会连带把另一页也筛掉。
      • 记录页的比赛筛选点开可以直接输入名字搜，点一行就生效、面板自动关掉；「重置」回到全部比赛。
      • 从成绩结构点进来的档位筛选会在筛选条下面留一个 chip，点它右边的 × 取消。
      • 数据页的统计只认「统计范围」：记录页的输赢 / 比赛 / 时间筛选都不会影响它。
      数据存在哪、怎么带走
      • 只保存在这台手机的浏览器里，不上传任何服务器；换浏览器、清缓存都会丢。
      • 换设备：旧设备「备份数据」导出 JSON → 新设备「从备份文件恢复」。
      • 「导出表格」是 CSV，给 Excel 或表格软件用。
      • 「清空全部数据」不可撤销，动手前先备份。
      • 万一账本文件读坏了，会弹出一页让你先把原始内容导出来留底，不会静默清空。
